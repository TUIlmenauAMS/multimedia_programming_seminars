Demo 3 — Manual SDP Video Call

04_mm_manual_sdp_video.html · No server · Google STUN · P2P video via copy-paste signaling

A real P2P video call between two browser tabs using manual SDP copy-paste as the signaling channel. You perform the signaling yourself — copying text between tabs. This makes the normally-invisible signaling process completely transparent.

What you do manually here is exactly what a signaling server automates in Demo 5. The data is identical — an SDP offer, an SDP answer, and ICE candidates. The only difference is the transport: here you copy-paste; in Demo 5, WebSocket does it automatically.
Requires camera + microphone. Open this file in two browser tabs on the same machine, or on two different machines sharing SDP text via any channel (chat, notes, email). On the same machine you call yourself — use headphones to avoid feedback echo.

Instructions

  1. Open this file in two tabs. In Tab 1, select Tab A — Caller. In Tab 2, select Tab B — Callee.
  2. Tab A: Click Start Call. Wait for the Offer SDP to appear, then copy it.
  3. Tab B: Paste the offer into Remote Offer, click Answer Call. Copy the Answer SDP that appears.
  4. Tab A: Paste the answer into Remote Answer, click Set Answer.
  5. Both tabs: Wait for ICE candidates to finish gathering (a few seconds). Click Copy ICE in each tab and paste into the other tab, then click Add ICE.
  6. Video should appear in both tabs. The connection state badge turns green.

// CONCEPT: Trickle ICE
ICE candidates arrive asynchronously after setLocalDescription() triggers ICE gathering. Wait a few seconds after Start Call / Answer Call for the ICE textarea to fill up before copying. The null candidate (end-of-gathering signal) is not included — only real candidates are shown.
// CONCEPT: srflx candidate — STUN at work
If you are behind NAT, you will see a candidate of type srflx alongside host candidates. The Google STUN server (stun.l.google.com:19302) told you your public IP:port. On the same LAN you will only see host. relay requires a TURN server (Demo 6).
