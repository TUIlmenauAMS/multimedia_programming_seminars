1. What is an Oscillator?

An OscillatorNode is a source node in the Web Audio API that generates a periodic waveform at a given frequency. It is the most fundamental building block for synthesizing sound in the browser — no audio file required.

The oscillator connects to the AudioContext destination (your speakers) through a GainNode that controls the volume. The signal chain is:

OscillatorNode → GainNode → AudioContext.destination

The four standard waveform types are sine, square, sawtooth, and triangle. Each has a distinct harmonic content and timbre.

3. How It Works

The AudioContext is the entry point for all Web Audio operations. Once created, you instantiate an OscillatorNode and a GainNode, connect them in series, and call oscillator.start(). The AnalyserNode taps into the signal to feed the oscilloscope canvas without affecting playback.

Note: Browsers require a user gesture (button click) before allowing audio playback. This is why the oscillator only starts when you press Start.
