Legend:
  [BUILT]      — generated by Claude; ready to use as-is
  [DOWNLOAD]   — you download this once (URL in DOWNLOAD.md or README)
  [YOU CREATE] — you create/edit this with your own content
  [GENERATED]  — created automatically at runtime; never edit by hand
  [GITIGNORE]  — excluded from version control

## Setup order

Do these steps in order — each one depends on the previous.

**1. Create the directory structure**

```bash
mkdir -p hometheater-demo/assets/models
mkdir -p hometheater-demo/assets/media
mkdir -p hometheater-demo/src/hometheater/web/vendor
mkdir -p hometheater-demo/cache   # or let the app create it on first run
```

**2. Place the [BUILT] files**

Copy the files Claude generated into the paths shown in the tree above.
The package layout must match exactly — `main.py` uses `Path(__file__).parent`
to locate sibling files, so relative positions matter.

```
pyproject.toml                  → hometheater-demo/pyproject.toml
README.md                       → hometheater-demo/README.md
src/hometheater/__init__.py     → hometheater-demo/src/hometheater/__init__.py
src/hometheater/main.py         → hometheater-demo/src/hometheater/main.py
src/hometheater/asset_pipeline.py → hometheater-demo/src/hometheater/asset_pipeline.py
src/hometheater/audio_engine.py → hometheater-demo/src/hometheater/audio_engine.py
src/hometheater/bridge.py       → hometheater-demo/src/hometheater/bridge.py
src/hometheater/web/index.html  → hometheater-demo/src/hometheater/web/index.html
src/hometheater/web/style.css   → hometheater-demo/src/hometheater/web/style.css
src/hometheater/web/scene.js    → hometheater-demo/src/hometheater/web/scene.js
src/hometheater/web/hud.js      → hometheater-demo/src/hometheater/web/hud.js
src/hometheater/web/vendor/DOWNLOAD.md → hometheater-demo/src/hometheater/web/vendor/DOWNLOAD.md
```

**3. Download the vendor JS files**

Follow the instructions in `src/hometheater/web/vendor/DOWNLOAD.md`.

**4. Drop your assets**

- Place your `.glb` models in `assets/models/`
- Place your video and FLAC in `assets/media/`

**5. Edit `assets/manifest.json`**

Use the schema in README §2. Filenames must match what you placed in step 4.

**6. Install and run**

```bash
cd hometheater-demo
uv sync
uv run python -m hometheater
```

## What gets committed to git vs. what doesn't

```
COMMIT these:
  pyproject.toml
  README.md
  src/hometheater/**          (all Python + web source files)
  assets/manifest.json        (schema only, no large binaries)

DO NOT COMMIT:
  assets/models/*.glb         (large binary assets)
  assets/media/               (large binary assets, possibly non-redistributable)
  cache/                      (generated; reproducible from source FLAC)
  src/hometheater/web/vendor/ (downloadable; large)
```

A `.gitignore` is provided that excludes these automatically.
